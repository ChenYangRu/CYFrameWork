# Text/ · 本地化文案

## 放什么

| 内容 | 格式 | 命名例 |
|---|---|---|
| 语言文案表 | `.json`（key → 文本） | `lore_zh_cn.json`、`lore_en_us.json` |
| 界面文案分表 | `.json` | `text_ui_zh_cn.json` |
| 剧情文本 | `.json` / `.bytes` | `story_chapter01_zh_cn.json` |

## 不许放

- 代码里的硬编码文案（新增文案必须走表）
- 未翻译的中间态（半中半英的表不许进包）
- 富文本里的裸 `<color=#FF0000>` 硬编码颜色（用语义标签，如 `{c_warn}`）

## 限制

| 项 | 规范 |
|---|---|
| key 命名 | `<模块>.<界面>.<语义>`，例 `ui.login.btn_login` |
| 编码 | UTF-8 无 BOM，`\n` 用 `\\n` 转义 |
| 单表大小 | ≤ 256 KB / 语言 |
| 语言集 | 至少 `zh_cn`；出海项目加 `en_us`、`ja_jp`、`ko_kr` |
| 占位符 | 统一 `{0}` `{1}`，禁止混用 `%s` / `{{name}}` |
| 长度 | 单条文案 ≤ 200 字（超长走剧情表分段） |

## 打包注意

- 只打**当前语言**的文案表（其余语言按需下载），全部语言一起进包会白占几 MB。
- 文案表与字体子集必须同步：新增中文字符后要重跑子集化脚本，否则真机显示方块。
- `Text/` 与 `Config/` 的更新频率最高，建议单独 bundle，避免与 UI 耦合。
