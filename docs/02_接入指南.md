## 一、加一个面板

### 1. 写面板类（热更层）

```csharp
using GameFramework.UI;
using UnityEngine;

namespace Game.HotUpdate
{
    public class ShopWindow : UIWindow
    {
        private Text _title;

        protected override void BuildUI()
        {
            var bg = UIUtil.CreatePanel("BG", transform, new Color(0.1f, 0.12f, 0.16f));
            UIUtil.Stretch(bg.rectTransform);

            _title = UIUtil.CreateText("Title", transform, "商 店", 48);

            UIUtil.CreateButton("Close", transform, "关闭", Close, new Vector2(240, 72));
        }

        protected override void OnShow()
        {
            // Args 是 Open 时传进来的任意对象
            var tab = Args as string;
            _title.text = string.IsNullOrEmpty(tab) ? "商 店" : "商 店 - " + tab;
        }

        protected override void OnUpdate(float dt) { /* 每帧，注意节流 */ }
    }
}
```

`UIWindow` 生命周期：`BuildUI`（仅一次） → `OnShow`（每次打开） → `OnUpdate`（每帧） → `OnHide`（每次关闭） → 销毁。

### 2. 注册 + 打开

```csharp
// GameEntry.Start() 里注册（只需一次）
UI.Register<ShopWindow>("Shop", UILayer.Normal);

// 任意业务处打开
UI.Open("Shop", "武器页");
UI.Open("Shop", args: null, onOpened: w => Debug.Log("已打开"));
```

### 3. 参数说明

| 参数 | 含义 |
|---|---|
| `name` | 面板唯一 key（字符串，跨程序集安全，不用类型名） |
| `layer` | `Scene/Normal/Popup/Top/Tips`；`Normal` 同层互斥，`Popup/Top` 压栈 |
| `prefabLocation` | 给了就走 YooAsset 加载 prefab；不给就走 `BuildUI()` 代码构建 |
| `fullScreen` | true 自动加半透明遮罩并挡穿透（弹窗用） |

### 4. 接美术资源时怎么切

```csharp
UI.Register<ShopWindow>("Shop", UILayer.Popup, prefabLocation: "UI/ShopWindow", fullScreen: true);
```

把 `ShopWindow` 组件挂到 prefab 根节点上，`BuildUI` 改成从 `transform.Find("...")` 取控件（或用 `OnBind`）。**接口不变，业务逻辑不用改。**

## 二、加一条协议

### 1. 定协议号

`Assets/Framework/Network/Cmd.cs`（AOT 层，要与服务端同步）：

```csharp
public const uint BuyItemReq = 2001;
public const uint BuyItemAck = 2002;
```

分段约定：`1~99` 系统 / `100~999` 登录 / `1000~1999` 玩家 / `2000~2999` 商店 / `9000+` 调试。

### 2. 包体约定（大端）

```csharp
// 请求：itemId(int) + count(short)
var body = new ByteBuffer(16);
body.WriteInt(itemId).WriteShort(count);

net.Request(Cmd.BuyItemReq, body, (ok, ack) =>
{
    if (!ok || ack == null) { GameLog.Warn("购买超时"); return; }

    var r = ack.ReadBody();
    int code = r.ReadInt();
    string msg = r.ReadString();
    if (code == 0) RefreshBag();
}, timeout: 8f);
```

### 3. 推送（服务端主动下发）

```csharp
// GameEntry.RegisterProtocols()
net.RegisterHandler(Cmd.KickOut, p => { /* 被踢下线 */ });
```

`Request` 用 `seq` 配对回包，**不要用它处理推送**；`RegisterHandler` 只处理 `seq == 0` 的包。

### 4. 注意事项

- 写/读顺序必须与服务端**逐字段一致**，错一个字段后面全乱（`ByteBuffer` 越界会立刻抛 `ProtocolException`，不会静默）。
- 字符串上限 65535 字节（`ushort` 长度前缀）；大文本用 `WriteBytes` + 自定义压缩。
- 单包上限 2MB（`Packet.MaxBodySize`），超了判定协议错乱并断连。
- 不要在 handler 里做重活（在主线程执行），重活 `GameLoop.Post` 到下一帧或起协程。

## 三、加载资源

```csharp
var res = ServiceLocator.Get<ResourceService>();

// 1) 加载资源对象（自行管理句柄）
yield return res.LoadAsset<Texture2D>("UI/Atlas/main", tex => { /* 用 */ });

// 2) 加载并实例化 prefab
yield return res.Instantiate("UI/ShopWindow", parent, go => { /* 拿到实例 */ });

// 3) 加载文本/二进制
yield return res.LoadRawBytes("Config/item_table", bytes => { /* 解析 */ });

// 4) 切场景
yield return res.LoadScene("Scene/Battle", LoadSceneMode.Single, ok => { });
```

**资源放哪**：`Assets/BundleAssets/**`（目录规范见 `Assets/BundleAssets/README.md`），热更 DLL 在 `BundleAssets/HotUpdate/`。
新增目录要在 `框架/资源/打开 YooAsset 收集器` 里加一条收集器，否则打包不进去。

> location = **相对 `BundleAssets/` 的路径去扩展名**（收集器用 `AddressByPathInBundleAssets`），
> 所以 `Assets/BundleAssets/UI/Shop/ui_shop_panel.prefab` → `UI/Shop/ui_shop_panel`。改目录名 = 改加载路径。

## 四、加一个业务模块

推荐结构（按功能分包，别按类型分包）：

```
Game/HotUpdate/
├─ GameEntry.cs              入口装配
├─ Login/
│   └─ LoginWindow.cs
├─ Main/
│   └─ MainWindow.cs
├─ Shop/
│   ├─ ShopWindow.cs
│   └─ ShopModel.cs          纯数据 + 业务规则（不碰 Unity）
└─ Common/
    └─ GameConst.cs
```

模块自注册（避免 `GameEntry` 越写越长）：

```csharp
public interface IGameModule
{
    void Register(UIManager ui, NetworkService net);
}

// GameEntry.Start()
var modules = new IGameModule[] { new ShopModule(), new BattleModule() };
foreach (var m in modules) m.Register(UI, Network);
```

## 五、配置怎么改

| 文件 | 改什么 | 生效时机 |
|---|---|---|
| `Resources/Config/launch.json` | 热更程序集名、补元数据名单、入口类 | 重开游戏 |
| `Resources/Config/resource.json` | 包裹名、运行模式、CDN 地址、并发 | 重开游戏 |
| `Resources/Config/network.json` | 服务器地址、心跳、重连 | 重开游戏（或做成 GM 面板热改） |

> ⚠️ `JsonUtility` **静默忽略** JSON 里未声明的字段。给 json 加字段时，必须同步在对应 C# 类的 `public` 字段里加，否则读到的永远是默认值——这个坑不报错，只表现为"配置没生效"。

## 六、业务侧能用的服务

```csharp
var res  = ServiceLocator.Get<ResourceService>();
var net  = ServiceLocator.Get<NetworkService>();
var ui   = ServiceLocator.Get<UIManager>();

EventBus.Subscribe<MyEvent>(OnMyEvent);      // 解耦模块
GameLoop.Instance.Post(() => { });           // 跨线程回主线程
var timer = new TimerService(); timer.Start(); timer.Delay(1f, () => { });
```

**热更层禁止**：注册新服务到 `ServiceLocator`、直接 `Resources.Load`、直接 `new Thread` 碰 Unity API。
