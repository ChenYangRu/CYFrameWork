# 05 · 资源目录规范（BundleAssets）

> 落地目录：`Assets/BundleAssets/`
> 每个子目录都有自己的 `README.md`（就地写规范），本文是**总览 + 体检清单**。
> 一句话：**目录即 location，命名即契约，不进收集器的资源等于不存在。**

---

## 一、目录树

```
Assets/BundleAssets/
├── README.md                 总纲（体积上限 / 命名 / 禁止项 / 分组策略）
├── UI/
│   ├── README.md
│   ├── Common/               通用组件、通用底框、界面字体      → builtin
│   ├── Login/  Lobby/  Battle/  Shop/                         → hotfix
├── Art/
│   ├── README.md
│   ├── Character/  Prop/  Effect/  Scene/                     → hotfix
│   └── Icon/                                                 → builtin
├── Audio/
│   ├── README.md
│   └── Bgm/  Sfx/  Voice/                                    → hotfix
├── Config/                   运营配置表（可热更）              → builtin
├── Text/                     本地化文案                       → builtin
├── Shader/                   自定义 shader + 变体集合          → builtin
├── Video/                    过场视频（点播，永不预载）        → hotfix
```

## 二、location 规则（最容易搞错）

收集器用自定义寻址规则 `AddressByPathInBundleAssets`：

```
location = 相对 Assets/BundleAssets/ 的路径，只剥一层扩展名
```

| 磁盘路径 | location |
|---|---|
| `Assets/BundleAssets/UI/Shop/ui_shop_panel.prefab` | `UI/Shop/ui_shop_panel` |
| `Assets/BundleAssets/Art/Icon/icon_item_crystal.png` | `Art/Icon/icon_item_crystal` |

为什么不用官方三条规则：

| 官方规则 | 输出 | 问题 |
|---|---|---|
| `AddressByFileName` | `ui_shop_panel` | 跨模块撞名（每个模块都有 `panel`） |
| `AddressByFolderAndFileName` | `Shop_ui_shop_panel` | 层级丢失、不可读 |
| `AddressByGroupAndFileName` | `UI_ui_shop_panel` | 同上 |

**代价**：改目录名 = 改代码里的加载字符串。这是有意的——改名必须显式发生，不能悄悄生效。

## 三、首包 vs CDN（分组策略）

| 分组 | 含 | tag | 策略 |
|---|---|---|---|
| `Builtin` | `UI/Common`、`Config`、`Text`、`Shader`、`Art/Icon` | `builtin` | 进首包（`Copy Buildin`） |
| `UI` | `UI/Login`、`Lobby`、`Battle`、`Shop` | `hotfix` | 进界面前下载 |
| `Art` | `Art/Character`、`Prop`、`Effect`、`Scene` | `hotfix` | 进战斗前预下载 |
| `Audio` | `Audio/**` | `hotfix` | 按场景预下载 |
| `Video` | `Video/**` | `hotfix` | 点播，永不预载 |

判定标准：**"玩家点开 App 到第一屏，缺了它会不会白屏/报错"** → 会 = builtin。

## 四、硬性限制（手游基准）

### 体积

| 项 | 上限 |
|---|---|
| 首包（Android AAB） | ≤ 30 MB |
| 微信小游戏首包 | ≤ 4 MB（平台硬限） |
| 单 bundle | ≤ 4 MB |
| 单资源文件 | ≤ 2 MB |
| 视频单文件 | ≤ 20 MB |

### 纹理

| 项 | 规范 |
|---|---|
| 图集 | 1024 优先，上限 2048 |
| 单图 | ≤ 512（图标 ≤ 128） |
| Read/Write | **关闭** |
| Mipmap | UI 关、3D 开 |
| 压缩 | Android ETC2/ASTC、iOS ASTC |

### 音频

| 类型 | 格式 | 上限 |
|---|---|---|
| BGM | OGG 96~128kbps | 1.5 MB |
| 音效 | OGG/WAV | 100 KB |
| 语音 | OGG 64kbps | 300 KB |

采样率统一 **44.1 kHz**。

### 命名

- 全小写 + 下划线，**禁中文/空格/大写/特殊字符**
- 目录深度 ≤ 4
- 同级禁同名不同扩展名
- 禁 `_old` / `_bak` / `副本` / `final2` 之类版本后缀

### 禁止进包

`.cs` / `Editor/` / 原始美术工程（PSD/FBX 源） / 第三方 Demo / 密钥 / 临时对比图

> 各目录内的 `README.md` 由自定义忽略规则 `DocIgnoreRule` **静默跳过**，不进包也不报警告。
> 新增文档格式（如 `.pdf`）要在这条规则里补扩展名。

## 五、打包前体检清单

```
□ 菜单「框架/资源/初始化 YooAsset 收集器」已执行（分组齐全）
□ YooAsset 收集器面板里，每个分组下都有收集器，且没有 "空收集器" 红字
□ 新增的目录已经加进收集器（最常见错误：目录在，收集器没加 → 打包后加载不到）
□ 未使用的孤儿资源已删除（全量收集会把它们都打进去）
□ 首包体积实测（看构建产物的 builtin 总量，不是看 Assets 目录大小）
□ 图集 Read/Write 已关闭、Mipmap 按规范设置
□ 音频全部 OGG，无 wav 母带
□ shader 变体集合已登记，无未使用 keyword
□ Text/ 只含当前语言
```

## 六、导入设置自动化（别靠人记）

规则代码在 `Assets/Editor/AssetImportRules/`，**数值唯一真相源 = `ImportRuleTable.cs`**。
新增资源时 AssetPostprocessor 自动套规则，不需要手工点 Inspector。

| 菜单 | 用途 |
|---|---|
| `框架/资源/导入规则/审计（只报告）` | 扫出存量资源里不合规的（含"规则版本落后"） |
| `框架/资源/导入规则/按规则重导` | 只重导不合规的，不会全量刷 |

三条关键认知：

1. **必须设平台覆盖**。只改 `TextureImporter.maxTextureSize`，真机仍会退回 RGBA32 未压缩 —— 1024² 从 0.5MB 变 4MB。
2. **AssetPostprocessor 只管新导入**。存量资源（从旧工程拷来的）必须跑一次「审计 → 重导」。
3. **改规则要 `RuleVersion + 1`**。版本戳写在 `AssetImporter.userData`（`gfrule:N`），靠它把存量标出来。

详见 `Assets/Editor/AssetImportRules/README.md`。

## 七、常见错误 → 根因

| 现象 | 根因 | 处置 |
|---|---|---|
| 编辑器里能看到，打包后加载不到 | 目录没加进收集器 | 「初始化 YooAsset 收集器」或手工加收集器 |
| 打包刷一屏 "Default asset cannot be packed" | 忽略了 `.md` 但用的是 `NormalIgnoreRule` | 确认 `IgnoreRuleName = DocIgnoreRule` |
| location 找不到 | 目录改名了 | location 是路径，改目录必须同步改代码字符串 |
| 材质变粉红 | shader 与材质分属不同 bundle | `Shader/` 打 builtin，确保先于材质加载 |
| 包体比预期大几 MB | 孤儿资源 / wav 母带 / 未压缩贴图 | 跑体检清单 |
| 首包超 30MB | builtin 分组塞了不该进的东西 | 只保留"首屏必需"，其余转 hotfix |
