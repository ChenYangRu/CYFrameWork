# 03 · 打包与资源更新

> 本框架**只做资源热更（YooAsset），不做代码热更**。
> 代码（`Game.Business`）随包发布；能换的是图、音、配置、prefab、shader。

---

## 一、为什么不做代码热更

| 原因 | 说明 |
|---|---|
| **平台不允许** | 微信小游戏等平台禁止运行时加载外部代码（`Assembly.Load` 视为违规），真机审核过不了 |
| 体积与成本 | 代码热更要带解释器/元数据补丁 + 双份程序集，首包与内存都更贵 |
| 出错代价高 | 代码热更出错是"全员白屏"；资源热更出错可以只回滚资源 |
| 收益有限 | 高频变更的是数值、活动、界面表现 —— 这些都在资源里 |

所以本框架**不含任何代码热更方案**（没有解释器、没有元数据补丁、没有 DLL 加载），换来：**启动少两步、包体更小、审核无风险**。
（`Game.Business` 仍保持独立程序集：分层清晰、增量编译快；只是不再被"加载"，而是随包编译。）

---

## 二、一次性准备（每个工程只做一次）

```
1) 菜单 框架/资源/初始化 YooAsset 收集器（首次必点）
2) 菜单 框架/资源/生成占位资源（可选，验证打包链路）
3) Assets/Resources/Config/resource.json 填 hostServer / appVersion
```

`resource.json`：`hostServer` 是 CDN 根（如 `https://cdn.example.com/mygame`），
实际资源地址 = `{hostServer}/{平台}/{appVersion}/{资源版本}/...`。

## 三、四种资源运行模式

| 模式 | 枚举 | 资源从哪来 | 更新流程 | 用在哪 |
|---|---|---|---|---|
| `EditorSimulate` | 0 | 直接读 AssetDatabase（模拟构建） | ❌ | 日常开发，改图即见 |
| `Offline` | 1 | 随包 StreamingAssets | ❌ | 单机包 / 无网环境验收 |
| `Host` | 2 | 内置兜底 + 远端下到本地沙盒 | ✅ | Android / iOS / PC 正式包 |
| `Web` | 3 | 全走 HTTP，不落磁盘 | ✅ | WebGL / 微信小游戏 |

**Host 与 Web 的本质区别**：Host 把 bundle 落到 `persistentDataPath`，能离线复玩；
Web 端没有可写文件系统（小游戏的虚拟 FS 语义也不稳定），只能边下边读 + 靠浏览器/平台缓存。

### 开发期怎么切（不改 json）

```
框架/资源/运行模式/编辑器模拟（EditorSimulate）
框架/资源/运行模式/离线单机（Offline）
框架/资源/运行模式/联机热更（Host）
框架/资源/运行模式/Web / 小游戏（Web）
框架/资源/运行模式/清除覆盖（跟随 resource.json）
框架/资源/打印当前资源模式        ← json 值 / 覆盖值 / 实际生效
```

覆盖值存 `EditorPrefs`，只在 `UNITY_EDITOR` 生效，**真机永远以 json / Bootstrap 为准**。

### 也可以在 Bootstrap 里选（进包生效）

`Bootstrap` 上有 `resourcePlayMode` 序列化字段，随场景进包，真机同样生效：

| 优先级（高 → 低） | 位置 |
|---|---|
| ① | `Bootstrap.resourcePlayMode`（Inspector） |
| ② | 菜单 `框架/资源/运行模式/*`（EditorPrefs，仅编辑器） |
| ③ | `resource.json` 的 `playMode` |

## 四、更新流程（Host / Web 共用，七段）

```
Initialize      初始化 YooAsset 包裹
  ↓
RequestVersion  拉远端 .version，比对本地版本
  ↓
LoadManifest    加载并校验清单
  ↓
Prefetch        比对差异，算出"要下几个文件 / 多少 MB"
  ↓
WaitConfirm     ★ 流量提示：把 FileCount / TotalBytes 交给 UI 问玩家
  ↓
Downloading     增量下载（进度 + 大小）
  ↓
Cleanup         清理不再使用的旧 bundle
  ↓
Done            进入业务
```

代码上是显式状态机：

```csharp
Resource.OnStageChanged += (stage, msg) => launchView.SetStatus(msg);
Resource.Stage;              // 当前阶段
Resource.PendingUpdate;      // FileCount / TotalBytes / RemoteVersion
```

### 下载确认（不能省）

```csharp
Resource.ConfirmDownload = (info, answer) =>
    ShowDialog(info.ToPlayerText(), ok => answer(ok));
```

- 回调必须被调用一次（`answer(true/false)`），否则启动会一直等
- 玩家拒绝 → 启动失败并提示"已取消更新"，不能静默继续
- 移动网络下静默吃掉几十 MB 是差评高发点，这条比任何加载优化都重要

## 五、打包：YooAsset 构建 → CDN

```
① 菜单 框架/资源/初始化 YooAsset 收集器        （首次 / 目录变了才需要）
② 菜单 框架/资源/打开 YooAsset 打包器           → 选平台 → Build
③ 菜单 框架/资源/同步构建产物 → CDN 目录        → 选构建产物目录
④ 上传 CDN：CDN/<平台>/<App版本>/<资源版本>/
⑤ 出包：Build Settings → Build（勾 Copy Buildin 才有首包资源）
```

### CDN 目录规范

```
CDN/
└─ WebGL/                     ← 平台目录（与 PathUtil.PlatformFolder 一致）
   └─ 1.0.0/                  ← appVersion（与 resource.json 一致）
      ├─ 2026-11-04-1200/     ← 资源版本（YooAsset 生成的时间戳目录）
      │   ├─ .version
      │   ├─ PackageManifest_xxx.bytes
      │   └─ *.bundle
      └─ 2026-11-03-0900/     ← 上一版（保留用于回滚）
```

### CDN 配置硬要求

| 项 | 要求 | 为什么 |
|---|---|---|
| `.version` | `Cache-Control: no-cache` | 否则玩家永远拿不到新版本 |
| 协议 | **https**（小游戏强制） | http 会被拦；`ws://` 同理 |
| 端口 | 只走 443 | 小游戏域名白名单按域名 + 端口校验 |
| CORS | 允许你的游戏域名 | WebGL 端是浏览器请求 |
| Bundle 名 | 纯英文（无中文/空格） | 部分 CDN 与平台对 URL 编码处理不一致 |

## 六、验证资源更新闭环（必做）

### A. 换资源（改图 / 改配置）

```
改一张图 → 重新 Build → 上传新版本目录 → 重开游戏
预期：启动页出现"下载 N 个文件 / X MB" → 进度条 → 进游戏看到新图
```

### B. 首包兜底（断网）

```
把设备网络断开 → 重开游戏 → 应能用随包资源进主界面（Host 模式）
```

### 判定失败在哪一环

| 现象 | 判据 |
|---|---|
| 启动页卡在"检查资源版本" | CDN 地址错 / `.version` 404 / 未配 CORS |
| 版本号不变 | `.version` 被缓存（检查响应头）或上传到了旧目录 |
| 下载 100% 但资源没变 | 下载到了别的包裹名 / 收集器没包含该目录 |
| 报 `Pack asset list is empty` | 收集器为空（`BundleAssets` 没有可打包资源） |
| 真机白屏但编辑器正常 | `EditorSimulate` 模式被打进真机包 |

## 七、Strip Level 与裁剪

不做代码热更后，裁剪配置简单很多：

- `Managed Stripping Level` 用默认（Medium）即可，**不再需要 `link.xml` 保活热更程序集**
- 但**反射入口没了**也意味着：业务里若用 `Type.GetType("字符串类名")`，仍要自己保活
- UI 字体、Shader Variant 仍按资源侧规则处理

## 八、一次完整发版的顺序清单

```
□ 1. 改完代码 → 全量编译通过（无 error）
□ 2. 菜单 框架/资源/导入规则/审计    → 资源体积/格式合规
□ 3. 菜单 框架/资源/打开 YooAsset 打包器 → Build（目标平台）
□ 4. 菜单 框架/资源/同步构建产物 → CDN 目录
□ 5. 上传 CDN（.version 关缓存、https）
□ 6. Build Settings 出包（确认 Copy Buildin / 平台 / 签名）
□ 7. 真机验证：断网可进（首包兜底）→ 联网有新版本提示 → 下载后资源生效
□ 8. 保留上一版资源目录（回滚用：把版本指针指回旧目录即可）
```

## 九、回滚

资源回滚比代码回滚简单：**CDN 上保留旧版本目录**，把版本指向旧目录即可。

| 层级 | 做法 |
|---|---|
| 远端 | 把 `.version` 指回旧版本（或临时把 `hostServer` 指到旧目录） |
| 本地 | 客户端清缓存后重启，会重新按远端清单下载 |
| 彻底 | 发新包（代码问题只能发版，这也是"不做代码热更"的代价） |
