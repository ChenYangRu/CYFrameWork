# 04 · 踩坑与判据表

> 用法：**先看现象，再看判据**。每条都标了"怎么确认"和"怎么改"，不要凭感觉改代码。
> 来源：框架实装过程中真实踩过的坑，按「现象 → 判据 → 处置」整理。每条都是先看到现象、再定位判据、最后给出可执行处置，不做推测式记录。

## 一、热更类（占线上事故 80%）

| # | 现象 | 判据（怎么确认） | 处置 |
|---|---|---|---|
| 1 | 真机报"类型或命名空间不存在"，编辑器正常 | 热更 asmdef 的 `autoReferenced` 是否为 `false` | 改成 false；确认没被编进 `Assembly-CSharp` |
| 2 | 编译不出 DLL，`HybridCLRData/HotUpdateDlls` 是空的 | `ProjectSettings/HybridCLRSettings.asset` 里 `hotUpdateAssemblies` 有没有这个程序集 | 跑菜单「0. 登记热更程序集」 |
| 3 | 热更 DLL 加载成功，但调 GameObject 报"类型不存在" | 缺补元数据 / 该 AOT 类型被裁切 | 跑菜单「2. 生成 AOT 补元数据」；Strip=High 时确认 `Link.xml` 有效 |
| 4 | `Assembly.Load` 抛 `BadImageFormatException` | `.dll.bytes` 是不是**当前** HybridCLR/Unity 版本编的 | 重新 GenerateAll，别复用旧 DLL |
| 5 | 热更后行为没变 | ① 主界面"业务逻辑版本"有没有变 ② CDN `.version` 有没有变 | 从 DNS/缓存两头查：`.version` 必须 `no-cache` |
| 6 | 编辑器热更代码不生效 | `AppDomain` 里的程序集是旧的（Domain Reload 没触发） | 关掉 Enter Play Mode Options 的 Domain Reload 禁用；或重启编辑器 |
| 7 | HybridCLR Installer 显示 √ 但 GenerateAll 报未安装 | 首次拉包慢，√ 只是包已就位 | 真正点 **Install**，等 `HybridCLRData/LocalIl2CppData` 生成 |

## 六、"看不见"类问题排查位序（跨模块通用）

日志全绿、坐标/开关全对，但**屏幕上什么都没有**，按这个顺序查（前面命中率最高）：

```
1. 层级/排序         → Canvas sortingOrder / 同一个 Canvas 下的 sibling 顺序
2. 是否真的激活      → gameObject.activeInHierarchy（父节点关了也算没激活）
3. 尺寸与锚点        → 宽高是不是 0；锚点算出来的 rect 是不是在屏幕外
4. 颜色 alpha        → Image.color.a 是否为 0（代码默认值常常是 (1,1,1,0)）
5. 遮罩/裁切         → Mask / RectMask2D 范围
6. ZTest / 相机      → 3D 物体被 ZTest 挡；UI 相机 cullingMask 没包含该层
7. 池化污染          → 对象是从池里取的，上一任留下的状态没清（本框架 `GameObjectPool` 会 SetActive(true)，但业务自身的字段要自己清）
```

> 判据：`Renderer.isVisible` / `rectTransform.rect` 打日志，比截图可靠。

## 八、本框架已知边界（别踩到墙上才知道）

1. **只实现 TCP**。WebSocket/KCP 需新增 `INetChannel` 实现；小游戏平台必须换（WebGL 不支持裸 Socket）。
2. **`UIUtil.DefaultFont` 用系统字体**，仅够 Demo。正式项目接 TMP + 子集化字体（中文必须 `Noto Sans SC`）。
3. **没有账号/存档/支付/统计 SDK**。这些是 AOT 层新增程序集（`GameFramework.Sdk`），不要塞进热更层——权限与回调都要求原生侧。
4. **热更程序集只有一个**。多热更程序集需要在 `launch.json` 按依赖顺序列出（被依赖的放前面），框架已按数组顺序加载。
5. **PlayerPrefs 存档**只适合小数据；大量数据请用 YooAsset 的 RawFile 或自建文件层。
6. **`AutoBoot` 兜底**会自动创建 Bootstrap，正式项目建议主场景显式挂载并关掉兜底，避免战斗场景重复启动。
